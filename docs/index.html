Act 1 — Resolve

resolveParent(registry, path) turns a declarative path descriptor into two concrete handles: the parent object and the final key to write to.

How it navigates

  1. Pick registry[path.fileName] as the root tree.
  2. If path.dataRole is set, call findByRole(root, dataRole) to jump to a labelled subtree.
  3. Walk every key in path.filePath except the last — each step descends one level.
  4. Return { parent, key } where key is the final element of filePath.

Example path

{
  "fileName": "base",
  "dataRole": "table-header-row",
  "filePath": ["children"],
  "action": "unshift"
}

With this path, resolveParent jumps to the node with data-role="table-header-row" inside the base tree, returning that node as parent and "children" as key.

Act 2 — Pick

actions/index.js is a plain object that maps action name strings to write functions. The orchestrator does:

const action = actions[path.action] || set;

Unknown names fall back to set — a safe, non-destructive default.

basic vs rows — basic.js writes to one node. rows.js fans out across every row, deep-cloning the value each time so rows never share object references.

Act 3 — Write

The orchestrator in index.js is intentionally minimal. It does not contain write logic — it only delegates:

const { parent, key } = resolveParent(registry, path);
const action = actions[path.action] || set;
action(parent, key, value);

Actions

Name File Type What it does
set basic.js basic Assigns value directly: parent[key] = value
push basic.js basic Appends value(s) to the end of parent[key]
unshift basic.js basic Prepends value(s) to the start of parent[key]
pushToRows rows.js rows Appends a deep-cloned value to every row's children
unshiftToRows rows.js rows Prepends a deep-cloned value to every row's children
unshiftSerialToRows rows.js rows Prepends a numbered clone (1, 2, 3…) to every row's children

Path Descriptor

The destinationPath object in an instruction JSON tells writePath everything it needs.

fileName
string
required
Key into the registry. Selects the root JSON tree to write into.
dataRole
string
optional
If present, findByRole is called to jump to the subtree whose data-role attribute matches this value before walking filePath.
filePath
string[]
required
Array of keys to descend through. The last element becomes key; every preceding element is walked as a parent.
action
string
optional
Name of the action to use. Falls back to set if omitted or unrecognised.

writePath in Context

writePath is the final step of runSingleInstruction. The pipeline for one instruction looks like this:

1
checkInstruction()
Guard — validates the instruction before doing any work
2
resolvePath(registry, sourcePath)
Read — pulls the source value out of the registry
3
applyTemplate(source, spec[templateKey])
Transform — builds the value to be written
4
writePath(registry, destinationPath, result)
Write — this module. Resolve, pick, mutate.
// runSingleInstruction — src/v5/index.js
const source = resolvePath(registry, instruction.sourcePath);
const result = applyTemplate(source, localSpec[templateKey]);
writePath(registry, instruction.destinationPath, result);
